# Материалы офисного хаба и испытаний

Скрипт: `OnlineTower 5.8/Scripts/create_environment_materials.py`.
Назначение: создать процедурную палитру для новой runtime-среды, без скачивания текстур или чужих моделей.

| Материал | Применение |
|---|---|
| M_OfficeWall | Тёплые белые стены и сплошной потолок |
| M_OfficeFloor | Серо-зелёный пол с мелкой тональной неоднородностью |
| M_OfficeMetal | Графитовые рамы и офисные металлические детали |
| M_OfficeWood | Тёплая древесная по цвету поверхность стойки и мебели |
| M_OfficeGlass | Непрозрачная глянцевая сине-зелёная панель окна |
| M_OfficeLight | Тёплые линейные потолочные светильники |
| M_MountainRock | Холодные скальные массы и горный горизонт |
| M_ArenaStone | Более светлая, читаемая поверхность арены |
| M_DungeonMetal | Тёмный металлический каркас фантастического коридора |
| M_DungeonGlow | Бирюзовые энергетические полосы |
| M_DesertSand | Тёплый охристый песок |
| M_DesertRock | Тёмный красноватый камень гор и скальных островков |
| M_Shrub | Матовый оливковый кустарник |

Цвета заданы в linear RGB. Материалы содержат параметры Tint, Roughness и Metallic; светящиеся — также Emission. Камень, песок, металл данжа, дерево, пол и кусты используют слабую world-space шумовую модуляцию цвета. Масштаб вычисляется в сантиметрах и не зависит от растяжения UV примитивов. Это стилизованные процедурные поверхности: дерево не имитирует точные волокна, пол не является физической моделью терраццо, кусты не используют листовые alpha-карточки.

Все материалы opaque, one-sided. M_OfficeGlass — стилизованная оконная панель, не прозрачное стекло. Для интерьера применяются реальные источники света в геометрии уровня: emissive сам по себе не гарантирует освещение закрытой комнаты.

## Запуск и сохранность

Запускать внутри Unreal Python после сохранения проекта и вне PIE. Скрипт создаёт только отсутствующие материалы в `/Game/Core/Materials`, проверяет результат соединения узлов и сохранения. Существующие материалы сохраняются без изменения; объект другого типа по занятому пути приводит к явной ошибке. Повторный запуск идемпотентен. Обновление палитры существующего ассета требует отдельной осознанной операции с резервной копией; скрипт не делает скрытого обновления.

Успешное завершение отмечается строкой `TOWER_ENV_MATERIALS_READY created=... kept=...`. Одна эта строка подтверждает создание/сохранение графов, но не визуальную приёмку или GPU-производительность. Для приёмки нужно дождаться компиляции шейдеров и осмотреть все четыре локации при их реальном освещении.

Это набор материалов для процедурной геометрии, а не готовый пакет авторских Blender-моделей. Изменений сторонних источников и импортов нет.
